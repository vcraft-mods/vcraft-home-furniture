# Vcraft ホーム家具（Minecraft 統合版アドオン）

家の中を作り込むための家具アドオン。テクスチャもモデルもコードも自作で、
バニラのアセットは 1 枚も含んでいません。

- 対応: **Minecraft 統合版 1.21.90 以上**
- 実験的機能（ベータAPI）のトグルは**不要**
- 言語: 日本語 / English

## 構成

```
HomeBP/            ビヘイビアーパック（ブロック定義・レシピ・スクリプト）
HomeRP/            リソースパック（モデル・テクスチャ・言語）
tools/             生成と検証のスクリプト（Node.js、依存ライブラリなし）
preview/           モデルの見え方を確認する HTML（生成物）
dist/              .mcaddon（生成物）
```

`HomeBP/blocks`、`HomeBP/recipes`、`HomeRP/models`、`HomeRP/textures`、`HomeRP/texts` は
**すべて `tools/` から生成されます**。手で直さず、生成スクリプト側を直してください。

## ビルド

```bash
node tools/build.js
```

テクスチャ生成 → コンテンツ生成 → 検証 → プレビュー → `.mcaddon` 作成 まで通しで実行します。
検証でエラーが出たらパッケージは作らずに止まります。

個別に動かす場合:

| コマンド | 内容 |
| --- | --- |
| `node tools/gen_textures.js` | PNG を全部描き直す |
| `node tools/gen_content.js` | ジオメトリ・ブロック・レシピ・言語ファイルを生成 |
| `node tools/validate.js` | Minecraft を起動せずに整合性をチェック |
| `node tools/preview.js` | `preview/index.html` にモデルの見え方を書き出す |
| `node tools/package.js` | `dist/*.mcaddon` を作る |
| `node tools/gen_site_images.js` | サイト用のギャラリー画像を書き出す |
| `node tools/update_site.js` | サイトのバージョン / サイズ / SHA-256 を更新 |

## 家具が1つも出てこないとき

ブロックは全部 **クリエイティブの「建材 / Construction」タブのいちばん下**に入ります
（検索タブで `chair` / `desk` / `dresser` / `carpet` と打つのがいちばん早い。
ゲームが英語表示なら名前も英語です）。

そこに1つも無い場合、原因はブロック定義ではなく**パックが読み込まれていない**ことです。
上から順に確認してください。

1. **ワールド設定の「ビヘイビアーパック」で有効にしたか**
   リソースパックだけ有効でも家具は出てきません。ビヘイビアーパック側も必ず有効にします。
2. **パックが灰色で選べないか**
   `min_engine_version` が `1.21.90` なので、それより古い Minecraft では選べません。
   設定 →「バージョン情報」で確認してください。
3. **ビヘイビアーパックが「依存パックが見つかりません」になっていないか**
   BP は `dependencies` に書いた **UUID とバージョンの両方**が一致する RP を探します。
   ここがズレていると BP だけ丸ごと読み込まれず、
   **リソースパックは普通に入るのに家具が1つも出ない**という状態になります
   （v1.0.1 がこれでした。バージョンを上げたとき依存側を上げ忘れると再発します）。
   `HomeBP/manifest.json` の `dependencies[].version` と
   `HomeRP/manifest.json` の `header.version` を必ず揃えてください。
   `node tools/validate.js` が検査します。
4. **ワールドに入ったとき紫のメッセージが出るか**
   `[Vcraft] ホーム家具 v1.0.2 を読み込みました` がチャットに出ればスクリプトまで動いています。
   出ないのに 1〜3 が問題ないなら、スクリプトモジュールの読み込みで止まっています。
5. **スクリプト抜きの診断用パックを試す**

   ```bash
   node tools/package.js --no-scripts
   ```

   `dist/VcraftHomeFurniture-v1.0.2-noscript.mcaddon` ができます。
   スクリプトモジュールと依存をマニフェストから外したもので、家具の見た目とレシピだけが入っています
   （座る・しまう等の動きはありません）。
   **これで家具が出るなら、原因はスクリプトモジュールの依存**です。
   その場合は `HomeBP/manifest.json` の `@minecraft/server` / `@minecraft/server-ui` の
   バージョンをゲームに合わせて下げてください。

設定 →「クリエイター」→「コンテンツログファイル」「コンテンツログ GUI」を ON にすると、
読み込みに失敗した本当の理由がゲーム内に表示され、
`%APPDATA%\Minecraft Bedrock\logs\ContentLog*.txt` にも残ります。
**原因の特定はここから始めるのがいちばん速い**（推測でマニフェストを触るより確実）。

## 覚えておくこと（ブロック定義）

- **`minecraft:display_name` は文字列**。`{ "value": "..." }` と書くと
  `minecraft:display_name: invalid string` でそのブロックが登録に失敗します。
  1つでも間違うと、そのブロックのレシピも `Recipe result malformed` で連鎖的に落ち、
  `blocks.json` も「レジストリに無い」と警告を出します。
  v1.0.2 まで 49 種すべてがこれで落ちていました（`node tools/validate.js` が検査します）。
- **ファイルは BOM 無しの UTF-8 で保存**。BOM が付くと統合版は JSON を読めません。

## 覚えておくこと

- **向きが東西で逆になる場合** — `tools/gen_content.js` の `ROTATION` で `east: 90` と
  `west: 270` を入れ替えて `node tools/build.js` を実行し直してください。
  統合版の `minecraft:transformation` の回転方向は実機で確認するのがいちばん早いです。
- **竹のはしごの登り方** — 統合版のブロックには「よじ登る」コンポーネントが無いため、
  スクリプトで浮遊効果を短時間かけて再現しています。はしごの中では常に上がるので、
  止まりたい／降りたいときはスニークしてください。
- **タンスの中身** — ブロックの位置に見えないエンティティ（`vcraft:storage`）を置いて
  そこに保管しています。壊したときは中身を出してエンティティも消しています。
